Could this be the end of BIOS-locked laptops? AI tweaker deploys Claude to unlock and change settings for good
============================================================

A Reddit user utilized the Claude Code AI assistant to reverse-engineer firmware on an HP 15-dw1036ne laptop, successfully unlocking 55 hidden setup fields and four configuration tabs.

### Key Points
- The modification bypassed the RSA-2048 signature verification by patching the firmware routine to return a success signal.
- The process involved using Ghidra for disassembly, UEFITool for extraction, and Unicorn Engine for emulation.
- Claude Code acted as an assistant to bridge documentation gaps, significantly reducing the time required for manual reverse-engineering.
- Successful implementation requires physical access to the motherboard via a hardware flash programmer and carries a risk of bricking the device.
- The unlocked firmware remains model-specific and leaves the laptop more vulnerable to potential future firmware-based security implants.

### Why it Matters
This development demonstrates how AI can lower the barrier to entry for complex firmware modification, potentially extending the lifespan of locked hardware that would otherwise become e-waste. While it offers a path for device recovery, it also highlights ongoing security vulnerabilities in hardware lacking robust, root-of-trust boot protection.
