SudoStamp
============================================================

A new authentication tool allows Linux users to approve sudo commands by using their Android phone's fingerprint sensor to sign requests securely over a local area network.

### Key Points
- The system utilizes the Android TEE or StrongBox to ensure biometric data and private keys never leave the mobile device.
- Authentication is handled via the pam_rssh module, which communicates with the phone over a local network using the ssh-agent protocol.
- If the phone is unavailable, denied, or times out after 60 seconds, the system automatically reverts to a standard password prompt.
- The solution requires Android 11 or higher with a Class 3 "strong" biometric sensor and supports major Linux distributions including Arch, Debian, Ubuntu, and Fedora.
- Security is maintained by requiring a fresh biometric signature for every request, preventing malware from signing without physical user interaction.

### Why it Matters
This integration offers a more convenient and secure alternative to traditional password-based sudo authentication by leveraging hardware-backed mobile biometrics. By keeping all sensitive operations local and offline, it provides a robust security layer that enhances workflow efficiency without introducing cloud-based vulnerabilities.
