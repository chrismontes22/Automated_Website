There are some files you don't want anyone to open, and this Android app takes care of them
============================================================

The open-source Android application AstraCrypt provides enhanced data security by using AES256-GCM encryption to protect sensitive files, offering a robust alternative to standard, non-encrypted file-hiding apps on mobile devices.

### Key Points
- AstraCrypt secures photos, videos, documents, and notes within a locked container using AES256-GCM and AEAD encryption algorithms.
- The app is open-source, allowing users to verify its security claims and confirming it does not collect or share personal data.
- Users can add an extra layer of security by setting a custom password and camouflaging the app interface as a calculator.
- The application is available for download via the Google Play Store or as an APK file directly from the project's GitHub repository.
- While effective, some users have reported occasional stability issues when importing large batches of media files.

### Why it Matters
AstraCrypt offers a transparent, high-security alternative for users whose devices lack built-in protection like Samsung’s Secure Folder. By utilizing verifiable encryption rather than simple file hiding, it provides a more reliable way to safeguard sensitive personal information from unauthorized access.
