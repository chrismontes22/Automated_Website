Cryptomator encrypts your files and folders before they sync to the cloud
============================================================

Cryptomator provides open-source, client-side encryption for cloud storage services, ensuring user data remains private and secure through AES-256 standards before files are ever uploaded to the cloud.

### Key Points
- Cryptomator uses AES-256 encryption to secure individual files and filenames before they are synced to cloud providers like Dropbox, Google Drive, and OneDrive.
- The software is fully open source, allowing for independent security audits and transparency regarding its encryption implementation.
- It supports cross-platform functionality across desktop and mobile devices, including local storage, USB drives, and network folders.
- The platform is GDPR-compliant and does not require users to provide personal data to function.
- Recent updates include technical improvements to the release pipeline, dependency upgrades, and various bug fixes for Windows and vault management.

### Why it Matters
This tool offers a critical layer of security for users who want to utilize cloud storage without trusting providers with their unencrypted data. By encrypting files locally, Cryptomator ensures that sensitive information remains inaccessible to third parties even in the event of a cloud service data breach.
