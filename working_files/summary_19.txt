Show HN: Bor – Open-source policy management for Linux desktops
============================================================

The Bor v0.8.0 release introduces new policy management for Thunderbird, Microsoft Edge, and Firewalld, alongside a comprehensive web UI overhaul and significant security hardening for enterprise Linux fleets.

### Key Points
- Adds native policy management for Mozilla Thunderbird, Microsoft Edge for Business, and Firewalld zones with tamper-protection.
- Overhauls the web interface using PatternFly 6, featuring server-side pagination, deep linking, and a modernized full-page policy editor.
- Implements granular per-action RBAC and enhanced security measures, including HKDF-derived encryption and improved MFA enforcement.
- Migrates frontend architecture to React 19.2 and updates core dependencies like gRPC 1.82.1 for improved stability and performance.
- Requires agents to be upgraded to v0.8.0 to support new policy types and updated protobuf schemas.

### Why it Matters
These updates provide administrators with more precise control over desktop and network security configurations across large-scale Linux environments. By modernizing the interface and hardening core security protocols, the release improves both operational efficiency and the overall integrity of managed fleets.
