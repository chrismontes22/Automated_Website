Vercel rolls out new protection against stolen session cookie attacks
============================================================

Vercel is implementing Device Bound Session Credentials to prevent information-stealing malware from reusing stolen session cookies by binding user logins to specific hardware-based security keys on local devices.

### Key Points
- Vercel is rolling out Device Bound Session Credentials (DBSC) to bind login sessions to a device's Trusted Platform Module (TPM).
- The feature prevents stolen session cookies from being used on unauthorized devices, complementing Chrome’s existing App-Bound Encryption.
- DBSC is currently available for Chrome users on macOS and Windows, with a gradual rollout to manage OAuth compatibility.
- Vercel also introduced a Security Review feature in public beta that scans GitHub code pushes for authorization flaws and exposed secrets.
- Security Review scans will remain free for Pro and Enterprise teams until November 10, 2026, with automated fixes billed separately.

### Why it Matters
These security enhancements represent a proactive effort by Vercel to protect developer environments following a significant data breach earlier this year. By adopting hardware-backed authentication and automated code scanning, the platform aims to mitigate risks posed by sophisticated malware and unauthorized access to sensitive project data.
