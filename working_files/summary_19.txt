Critical PHP Core Security Flaws Affect Websites, Including WordPress via @sejournal, @vahandev
============================================================

The PHP security team released emergency patches on October 21, 2026, to address two critical vulnerabilities that allow unauthorized remote code execution on vulnerable web servers.

### Key Points
- PHP versions 8.5.12, 8.4.27, 8.3.36, and 8.2.35 contain the necessary security fixes for these critical flaws.
- Apache servers utilizing mod_php are at the highest risk, as attackers can execute code before the website's own scripts load.
- Website owners must contact their hosting providers to verify or install the updates, as updating WordPress or plugins does not patch the underlying PHP.
- PHP 8.1 and older versions are end-of-life, though limited source-code fixes are available for versions 7.4, 8.0, and 8.1.
- Several government and university websites in the Netherlands and Finland were taken offline as a precautionary measure prior to the patch release.
- Security experts recommend auditing sites for existing compromises, such as web shells, because patching does not remove unauthorized access already gained by attackers.

### Why it Matters
These vulnerabilities pose a severe threat to website integrity and user data, as they allow attackers to bypass authentication and execute arbitrary code. Because exploit tools are already circulating, immediate action is required to prevent potential breaches that could lead to long-term damage to site security and search engine visibility.
