Now generally available: Preview client-side encrypted PDF and image files directly in Google Drive
============================================================

Google Drive now allows users to preview client-side encrypted PDF and image files directly in their web browsers, eliminating the need to download sensitive documents for viewing.

### Key Points
- Google introduced native previewing for client-side encrypted (CSE) PDF and image files within the Drive interface.
- The feature removes the requirement to download encrypted files to local devices, enhancing both security and user productivity.
- This update is available by default for all authorized users with no additional administrative configuration required.
- The rollout began on October 15, 2026, for Rapid Release and Scheduled Release domains.
- Availability is restricted to specific Google Workspace editions, including Enterprise Plus, Education Standard, and Assured Controls.

### Why it Matters
This update streamlines workflows for organizations handling highly confidential data by reducing the security risks associated with downloading sensitive files to local hardware. By keeping encrypted content within the browser environment, businesses can maintain stricter control over their information while improving operational efficiency for end users.
