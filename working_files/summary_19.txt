mobsf 4.6.4
============================================================

The Mobile Security Framework (MobSF) is an open-source platform providing automated static and dynamic analysis for Android, iOS, and Windows mobile applications to enhance security and privacy.

### Key Points
- Supports static analysis for various binaries including APK, XAPK, AAB, IPA, and source code.
- Enables dynamic analysis on emulators, simulators, and physical devices using Frida Gadget for runtime inspection.
- Integrates into DevSecOps and CI/CD pipelines through REST APIs and CLI tools.
- Available as a Docker container for rapid deployment and bundled with security distributions like BlackArch and Pentoo.
- Recently released version 4.6.4, which is available for download via PyPI with verified provenance metadata.

### Why it Matters
MobSF streamlines the mobile application security testing process by automating complex tasks like malware analysis and penetration testing. Its integration capabilities allow development teams to identify vulnerabilities early in the software development lifecycle, significantly reducing security risks in production environments.
