CloudSyncD MacOS Backdoor Hides Behind Fake Zoom Installer
============================================================

Security researchers at Jamf Threat Labs have identified a new macOS backdoor named CloudSyncD, which disguises itself as a fake Zoom installer to gain elevated system privileges.

### Key Points
- The malware uses a deceptive disk image to trick users into bypassing macOS Gatekeeper security protections.
- CloudSyncD prompts users for their local login password, which it stores locally in a decoy file using hidden Unicode characters.
- The backdoor utilizes a universal Mach-O binary compatible with both Apple silicon and Intel-based Mac computers.
- Once executed, the malware establishes a hidden directory and communicates with command-and-control infrastructure to receive remote tasks.
- Unlike typical credential stealers, this implant focuses on remote code execution rather than harvesting browser data or Keychain items.

### Why it Matters
This discovery highlights the evolving sophistication of macOS threats that rely on social engineering to bypass built-in security features. By masquerading as legitimate software, these attacks pose a significant risk to users who may inadvertently grant malicious installers administrative access to their systems.
