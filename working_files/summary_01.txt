A supposed GTA 6 build is going around the internet, but don't be fooled: it's fake and full of malware
============================================================

Cybercriminals are distributing a fraudulent 113GB file disguised as a leaked build of Rockstar Games' upcoming title Grand Theft Auto 6 to infect user computers with malicious software.

### Key Points
- Security researchers identified a fake 113GB GTA 6 installer circulating on various torrent websites.
- Reverse-engineering of the files confirmed the package contains malicious code rather than actual game data.
- Experts warn that the file size is unrealistic given the expected scale of the upcoming Rockstar Games title.
- Users are advised to avoid downloading any unverified game files to prevent potential system compromise and data theft.

### Why it Matters
High-profile game releases frequently attract scammers who exploit fan anticipation to distribute malware through unofficial channels. This incident serves as a critical reminder for users to rely exclusively on official distribution platforms to maintain cybersecurity and protect personal data.
