Researchers Push Over 2 Million Updates to Remotely Disable Popcorn Time Updater That Could Fuel a Botnet
============================================================

Dutch security firm Eye Security disabled a dangerous background updater in the abandoned Time4Popcorn app by pushing over 2 million remote updates to vulnerable Windows and Mac computers.

### Key Points
- Eye Security identified a critical vulnerability, tracked as CVE-2026-30612, in the abandoned Popcorn Time fork known as Time4Popcorn.
- The flaw allowed the software to install unauthorized code at the highest system privilege level via unencrypted connections to expired web domains.
- Between November 2025 and March 2026, Eye Security pushed updates to disable the vulnerable updater on millions of affected devices globally.
- The U.S. Cybersecurity and Infrastructure Security Agency (CISA) assigned the vulnerability a high severity score of 9.8 out of 10.
- Eye Security transferred control of the hijacked domains to the non-profit Shadowserver Foundation in March 2026 to prevent future exploitation.

### Why it Matters
This operation highlights the significant security risks posed by abandoned software that maintains persistent, high-privilege background processes. While Eye Security successfully mitigated the immediate threat, users remain vulnerable if they continue to run the outdated application, which lacks modern security protections.
