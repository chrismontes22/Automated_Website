OpenBSD 8.0 Brings Expanded Hardware Support, Security Enhancements, and Virtualization Improvements
============================================================

OpenBSD 8.0 introduces significant hardware compatibility updates, including Intel Arc GPU support and expanded virtual address space, alongside critical security enhancements through LibreSSL 4.4.0 and OpenSSH 10.6.

### Key Points
- The AMD64 kernel virtual address space increased from 4 GB to 512 GB to support high-VRAM graphics cards.
- Virtual machine capabilities now include support for up to 64 virtual CPUs per guest via vmm/vmd.
- New hardware support includes Intel Arc A-Series GPUs, Qualcomm WCN7850 wireless adapters, and various RISC-V platform improvements.
- OpenSSH 10.6 disables LZ77 compression and restricts specific characters in usernames to mitigate shell injection vulnerabilities.
- The httpd daemon added support for custom HTTP headers, request filtering rules, and improved HTTPS crypto methods.

### Why it Matters
This release strengthens OpenBSD's position as a secure, stable operating system by modernizing its hardware support and virtualization capabilities. These updates allow the platform to remain competitive for specialized computing tasks while maintaining its long-standing commitment to rigorous security standards.
