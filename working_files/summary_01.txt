Synopsys CXL 4.0 IP Hits 128 GT/s, Claims 3-6x KV Cache Offload Over SSDs
============================================================

Synopsys has launched the industry’s first complete Compute Express Link 4.0 intellectual property suite, providing essential tools for designers to build high-performance, scalable AI infrastructure systems.

### Key Points
- The suite includes a CXL 4.0 controller, IDE security modules, a PCIe 7.0-based physical layer, and verification IP.
- CXL 4.0 doubles bandwidth to 128 GT/s, enabling aggregate speeds exceeding 4 TB/s when using eight x16 links.
- The technology supports disaggregated memory architectures, allowing for rack-scale memory pools that can exceed 100 TB.
- Integrated IDE security modules provide AES-GCM encryption and authentication to support confidential computing in multi-tenant AI environments.
- The IP is hardened for advanced process nodes ranging from 5nm to 2nm to meet the requirements of modern hyperscale SoC designs.

### Why it Matters
This release addresses critical memory bottlenecks in AI infrastructure by enabling faster, more efficient data movement between processors and accelerators. By reducing latency and lowering inference costs, these tools help hardware designers keep pace with the rapidly increasing demands of large-scale AI model deployment.
