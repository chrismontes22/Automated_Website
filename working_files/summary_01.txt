China-Aligned Hackers Hijack Sogou Input Method DNS Requests to Deploy DarkVigil Backdoor
============================================================

The China-aligned threat actor SlippyNunchucks is exploiting insecure HTTP communications in the Sogou Input Method to deploy the DarkVigil surveillance implant across multiple Asian and European nations.

### Key Points
- SlippyNunchucks has targeted organizations and individuals in Hong Kong, Thailand, Japan, Vietnam, Oman, and Sri Lanka since July 2026.
- The attack uses DNS hijacking to intercept HTTP requests and deliver malicious configurations via the legitimate Sogou component SGTool.exe.
- DarkVigil is a modular .NET framework that utilizes over 20 plugins and the Duplex Message Transport Protocol for command-and-control operations.
- Other applications compromised by the group include QuickFox, QingTalk, MiYunChat, SoftCam, and tawk.to.
- Tencent patched the underlying vulnerability, tracked as CVE-2026-120422, in version 16.10 of the Sogou Input Method on October 29, 2026.

### Why it Matters
This campaign highlights the significant risks posed by supply chain compromises that weaponize widely used, trusted software to bypass traditional security perimeters. By forcing a transition from insecure HTTP to encrypted HTTPS, the patch mitigates this specific vector, but the incident underscores the ongoing threat of nation-state actors targeting Chinese-speaking populations globally.
