Hiding Virtualization From Other Software
============================================================

The new vfio-native tool modifies Linux Kernel-based Virtual Machine environments to mimic bare-metal hardware, significantly reducing the ability of software to detect that it is running inside a virtual machine.

### Key Points
- The vfio-native tool applies kernel patches to obscure virtual machine signatures and force CPU behavior to match physical hardware.
- Standard KVM virtual machines score 10/85 on detection tests, while systems using vfio-native achieve a score of 1/85.
- The software is currently available for users to install via the Arch User Repository (AUR).
- Security researchers use the tool to observe malware behavior that might otherwise remain dormant when detecting a virtualized environment.
- The tool helps run legacy industrial software that often fails to operate when it identifies a virtual machine host.

### Why it Matters
This development provides a critical solution for researchers and engineers who need to bypass restrictive hardware-detection checks in legacy or security-sensitive applications. By masking virtualization, it ensures that software functions consistently across both physical and virtualized infrastructure.
