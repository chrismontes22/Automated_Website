R2Socks
============================================================

A new SOCKS5 proxy tool leverages Cloudflare R2 object storage to tunnel TCP traffic, enabling covert network communication through encrypted binary packets stored as temporary bucket objects.

### Key Points
- The tool uses Python for the proxy and offers both Python and dependency-free C++ agents for Windows-based target systems.
- Communication relies on polling R2 buckets, where connection requests and data are serialized into binary packets and stored as objects.
- It supports optional AES-256-GCM encryption for payloads, utilizing PBKDF2-SHA256 key derivation with 600,000 iterations.
- The system employs adaptive sleep intervals and batching to balance network responsiveness with API call volume and efficiency.
- The C++ agent is built using native Windows APIs, including WinHTTP, bcrypt, and Winsock2, requiring no external library dependencies.

### Why it Matters
This technique demonstrates how cloud storage services can be repurposed as covert command-and-control channels to bypass traditional network security perimeters. Security teams should monitor for unusual traffic patterns or high-frequency object creation within R2 buckets that may indicate unauthorized data exfiltration or proxy activity.
