Microsoft Says New Cybersecurity AI Model Helps MDASH Hit 95.95% at Half the Cost
============================================================

Microsoft has launched MAI-Cyber-1-Flash, a specialized cybersecurity model integrated into its MDASH vulnerability remediation harness, designed to improve efficiency and reduce operational costs for enterprise security teams.

### Key Points
- MAI-Cyber-1-Flash is a 137-billion parameter sparse mixture-of-experts model featuring a 256,000-token context window.
- The model is currently available in private preview via Azure AI Foundry for approved MDASH customers.
- Microsoft reports a 95.95% score on the CyberGym benchmark when pairing the new model with GPT-5.4.
- The configuration reportedly reduces system costs by 50% compared to previous MDASH model combinations.
- MAI-Cyber-1-Flash is the first component of Project Perception, a broader defensive security agent system launching August 3.

### Why it Matters
This release highlights a strategic shift toward specialized, cost-effective AI agents that handle routine security tasks while reserving more powerful models for complex challenges. By optimizing the system architecture, Microsoft aims to make automated vulnerability remediation more accessible and scalable for enterprise security operations.
