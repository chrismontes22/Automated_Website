Chrome will now show a warning before you visit ‘suspicious’ sites
============================================================

Google is rolling out a new two-stage warning system for Chrome’s Enhanced Protection mode that alerts users to potentially suspicious websites before they navigate to the page.

### Key Points
- The feature distinguishes between "suspicious" sites with lower-confidence risk and "dangerous" sites with high-confidence threats.
- Suspicious site warnings appear as pop-ups, while dangerous site alerts occupy the full screen with a red background.
- Users can manually override suspicious site warnings by selecting a "Mark as safe" option if they believe the flag is incorrect.
- This update builds upon the two-stage file download security system Google introduced earlier in 2024.
- Google has simultaneously integrated improved Gemini-powered scam detection for users enrolled in Enhanced Protection.

### Why it Matters
This update provides users with more granular security data, allowing for better-informed browsing decisions when encountering potentially malicious URLs. By differentiating between varying levels of risk, Google aims to reduce accidental exposure to phishing and malware while minimizing user frustration from false positives.
