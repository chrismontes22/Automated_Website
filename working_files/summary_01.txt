Claimed Bug Bounty Hunter Likely Used LLM to Build PhantomRaven npm Stealer
============================================================

A financially motivated threat actor is distributing the PhantomRaven information stealer via malicious npm packages to compromise developer environments and exploit corporate bug bounty programs for illicit gain.

### Key Points
- CrowdStrike identified PhantomRaven, a JavaScript-based malware likely generated using large language models, distributed through over 100 typosquatted npm packages.
- The malware targets authentication tokens, CI/CD secrets, and GitHub credentials from developers' machines to gain unauthorized access to corporate systems.
- The operator, active since November 2022, uses compromised data to identify and report vulnerabilities, claiming rewards from at least nine technology and retail bug bounty programs.
- Attackers utilized remote dynamic dependencies to bypass security detection tools while harvesting system fingerprints, environment variables, and Git configurations.
- Evidence suggests the threat actor has expanded operations to the Python Package Index (PyPI) using similar malicious code patterns.

### Why it Matters
This campaign demonstrates a sophisticated shift where attackers use proprietary malware to gain leverage for fraudulent bug bounty claims rather than selling stolen data on illicit markets. It highlights the growing risk of supply chain attacks and the increasing efficiency of threat actors who leverage generative AI to automate malicious code development.
