PEERSTITCH Malware Deployed via FortiOS Flaw Bypasses Checks on Tagged VPN Sessions
============================================================

Threat actors are exploiting a Fortinet FortiOS vulnerability to deploy PEERSTITCH, a sophisticated memory-resident malware that evades detection by operating within legitimate system processes on ARM64 devices.

### Key Points
- Attackers exploited CVE-2025-61624, a path traversal flaw in FortiOS, to inject the PEERSTITCH malware into memory.
- PEERSTITCH avoids disk persistence and network listeners by using a covert communication bridge between the miglogd and iked daemons.
- The intrusion, tracked as CL-STA-0954, began by compromising a FortiManager appliance to steal credentials and configurations for over 500 firewalls.
- The malware uses an Emscripten-based orchestrator to inject malicious code into running processes via ptrace, bypassing standard security validations.
- CISA added CVE-2025-61624 to its Known Exploited Vulnerabilities catalog in October 2026, mandating immediate patching for federal agencies.

### Why it Matters
This campaign demonstrates the increasing technical maturity of attackers targeting centralized edge management ecosystems to gain deep access into downstream networks. By weaponizing legitimate processes and avoiding disk-based artifacts, the malware effectively bypasses traditional endpoint detection and network monitoring tools.
