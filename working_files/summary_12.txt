Fake iPhone Duo preorder scam triggers DarkSword attack
============================================================

Scammers are using a sophisticated fake iPhone Duo preorder website to launch the DarkSword exploit chain, which can compromise unpatched iPhones simply by visiting the malicious page.

### Key Points
- The fraudulent site mimics Apple’s design to lure users with a fake $500 voucher for the upcoming iPhone Duo.
- Opening the page triggers the DarkSword exploit chain, which attempts to bypass iOS security without requiring any user interaction or form submission.
- If successful, the malware targets cryptocurrency wallets, saved keychain credentials, Apple Notes, and personal communication data.
- The exploit specifically targets older, unpatched versions of iOS, though it may attempt to load on any device using the Safari browser.
- Apple has previously released security patches for the vulnerabilities used in the DarkSword chain, making software updates the primary defense against this attack.

### Why it Matters
This attack highlights a significant shift in mobile threats where merely visiting a website can lead to a full device compromise without any user input. Users should prioritize installing the latest iOS updates and avoid clicking on unsolicited preorder links to protect their sensitive financial and personal data.
