Chrome just flagged a hugely popular extension as unsafe
============================================================

Google has removed the popular GoFullPage extension from the Chrome Web Store after flagging the tool as unsafe, causing widespread concern among its 11 million active users.

### Key Points
- GoFullPage, a widely used screenshot utility, was abruptly disabled across Chrome and Brave browsers due to a policy violation.
- Developers confirmed the removal resulted from a copyright dispute rather than a security compromise or malware infection.
- Google is currently working with the GoFullPage team to resolve the issue and restore the extension to the Chrome Web Store.
- Users are advised to avoid unofficial versions of the software and can use Chrome’s built-in DevTools as a temporary alternative.

### Why it Matters
This incident highlights how automated security warnings in web browsers can cause unnecessary alarm when policy enforcement is conflated with malware detection. It serves as a reminder for users to verify the source of software alerts before assuming a security breach has occurred.
