I didn't need a Kindle to get the reading experience I wanted
============================================================

Users can bypass the limitations of dedicated Kindle hardware by combining the official Amazon Kindle app with the open-source KOReader software on existing Android mobile devices.

### Key Points
- The Kindle app maintains access to Amazon’s ecosystem, while KOReader supports diverse file formats including EPUB, PDF, CBZ, and Markdown.
- KOReader is an open-source project with nearly 30,000 GitHub stars, featuring advanced typography controls, PDF reflow, and automated highlight exports to note-taking apps.
- Users can install KOReader via GitHub or F-Droid, though the process requires sideloading and manual configuration of cloud storage or Calibre for file syncing.
- Amazon hardware restrictions, such as the removal of USB transfer options and lack of native EPUB support, have prompted users to seek more flexible alternatives.
- KOReader does not support DRM-protected content, meaning library books and protected purchases must still be managed through official Amazon or Libby applications.

### Why it Matters
This approach allows readers to consolidate their digital libraries on a single device while avoiding the restrictive "walled garden" of proprietary e-reader hardware. By leveraging open-source tools, users gain greater control over document formatting and file management without the recurring cost of purchasing new dedicated hardware.
