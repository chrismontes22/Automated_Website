Bringing post-quantum cryptography to geographically fenced key management
============================================================

Cloudflare has launched a post-quantum GeoKey Manager in closed beta to help customers enforce data sovereignty by restricting decryption key access to specific geographic regions.

### Key Points
- The system uses hybrid ML-KEM-768 and X25519 cryptography to protect against "harvest now, decrypt later" quantum computing threats.
- Decryption keys are wrapped so they can only be unwrapped by Cloudflare edge servers physically located within a customer's designated region.
- The architecture utilizes Trusted Platform Module (TPM) hardware identity and server inventory data to authorize edge servers for specific regional root keys.
- Keys are stored in volatile memory within the Linux kernel keyring to prevent persistent storage and reduce potential attack vectors.
- General availability for the new GeoKey Manager is currently scheduled for Q1 2027.

### Why it Matters
This technology allows organizations with strict regulatory requirements to maintain high-performance global operations while ensuring sensitive data remains decrypted only within authorized borders. By integrating post-quantum security, Cloudflare provides a future-proof solution for enterprises concerned about long-term data exposure to emerging quantum decryption capabilities.
