I stopped letting Windows decide where my files go, and my SSD stopped filling up
============================================================

Windows 11 users can optimize storage capacity and performance by manually reconfiguring default settings that force cloud data, new downloads, and system files onto the primary boot drive.

### Key Points
- OneDrive storage can be moved to a secondary drive by unlinking the account and re-syncing the folder to a new location.
- Users can redirect new file downloads to a different drive via Settings, System, Storage, and Advanced Storage Settings.
- The 12.5GB hiberfil.sys file can be removed by running the "powercfg /hibernate off" command in an elevated command prompt.
- Disabling hibernation also turns off the Windows Fast Startup feature, which may impact boot times on some desktop systems.
- Managing these settings prevents the boot drive from reaching critical capacity and reduces unnecessary write cycles on high-performance NVMe SSDs.

### Why it Matters
Taking manual control over Windows 11 storage prevents the boot drive from becoming unnecessarily cluttered with cloud data and system files. This optimization helps users maximize their existing hardware capacity and extends the lifespan of primary SSDs by reducing constant write operations.
