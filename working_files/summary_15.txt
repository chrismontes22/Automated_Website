FADU puts the filesystem inside the SSD's flash to bypass host CPUs
============================================================

FADU has unveiled its File-Semantic SSD (FS-SSD) technology, which integrates file system operations directly into the drive to enable host-free data access for GPUs and accelerators.

### Key Points
- The FS-SSD architecture offloads file system, block layer, and CPU tasks to the drive, potentially reducing CPU cycle consumption by 30%.
- FADU utilizes the NFSv3 protocol to handle path lookups, access control, and file-to-flash mapping within standard NVMe commands.
- Preliminary testing shows the technology maintains high throughput even when server resources are significantly reduced, outperforming traditional Linux NFS-over-RDMA.
- The design reduces write amplification by 63% by eliminating the "double garbage collection" conflict between host file systems and SSD firmware.
- FADU expects to provide partner samples by Q3 2027, with a hostless JBoF reference design planned for the end of 2027.

### Why it Matters
By moving file management directly onto the storage controller, this technology could significantly lower latency and power consumption for data-intensive AI and high-performance computing workloads. This approach allows GPUs and DPUs to access data without relying on a traditional host CPU, potentially reshaping the efficiency and cost structure of large-scale storage infrastructure.
