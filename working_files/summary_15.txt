Node2Shell evolves to HTTP2Shell, blast radius affects many HTTP libs and apps
============================================================

A critical security vulnerability, CVE-2026-111497, in the Google Brotli compression library allows remote attackers to execute arbitrary code or leak memory across multiple programming languages and applications.

### Key Points
- The flaw, dubbed "node2shell," is an out-of-bounds write vulnerability affecting Brotli versions 1.0.3 through 1.2.0.
- It carries a critical CVSS v4.0 score of 9.2, enabling unauthenticated remote code execution via crafted Brotli-compressed data.
- Major affected ecosystems include Node.js, Python, Bun, Envoy, and Istio, requiring immediate updates to patched versions like Brotli 1.2.1.
- Vulnerable Python packages include `Brotli` and `brotlicffi`, which are often loaded automatically by popular HTTP clients like `requests` and `httpx`.
- Automated security tools may not yet flag this CVE, necessitating manual dependency audits and container image rebuilds.

### Why it Matters
This vulnerability poses a significant risk because Brotli is a ubiquitous compression standard that is often bundled as a hidden dependency in web applications. Because the flaw can be triggered by both inbound requests and outbound data fetches, unpatched systems remain exposed to potential remote takeovers by malicious actors.
