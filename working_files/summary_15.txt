OpenSSL 4.1.0: What’s new, what’s removed, and what’s still broken
============================================================

The OpenSSL project has released version 4.1.0, introducing support for DTLS 1.3 while simultaneously documenting four known bugs and removing several legacy build configurations and platform targets.

### Key Points
- OpenSSL 4.1.0 adds support for DTLS 1.3, though the project warns of four specific bugs affecting connection states, handshakes, and session ticket retransmissions.
- The release removes the no-ecdsa and no-ecdh build flags, requiring users to utilize no-ec to disable elliptic curve support entirely.
- Support for Windows-on-Itanium and Windows CE build targets has been dropped, and the tsget utility now requires the Net::Curl::Easy Perl module.
- Performance optimizations include faster post-quantum algorithms like ML-KEM and ML-DSA, alongside AVX-512 and VAES improvements for AES-CBC decryption on x86_64.
- New features include RFC 8701 GREASE support, an IKEv2 key derivation function, and initial compatibility for the Elbrus2000 architecture.

### Why it Matters
These updates introduce critical security and performance enhancements, but the documented DTLS 1.3 bugs pose significant risks for developers building network applications. Organizations must carefully evaluate these changes to avoid connection failures and ensure their infrastructure remains compatible with the updated build requirements.
