SolidCraft is Parametric, Automation-friendly CAD for Desktop and Browser
============================================================

SolidCraft is a new open-source 3D modeling CAD suite written in Rust that features a parametric timeline and built-in support for AI agent integration via MCP.

### Key Points
- SolidCraft supports essential CAD functions including sketches, solid modeling, constraints, and a parametric feature timeline.
- The software is built entirely in Rust and functions as both a desktop application and a browser-based web app.
- Every user action is executed as a command with JSON parameters, enabling a headless command-line interface.
- The platform includes a Model Context Protocol (MCP) server designed to allow AI agents to interact with the software.
- The project is currently in early development, with a live online demo available for users to test features.

### Why it Matters
This software represents a modern approach to CAD by prioritizing automation and interoperability with AI-driven workflows. Its browser-based architecture and command-driven design could lower barriers for developers looking to integrate 3D modeling into broader automated engineering pipelines.
