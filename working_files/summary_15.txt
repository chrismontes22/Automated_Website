affaan-m/ECC: The agent harness performance optimization system. Skills, instincts, memory, security, and research-first development for Claude Code, Codex, Opencode, Cursor and beyond.
============================================================

ECC (Engineering Coordinated System) is an open-source toolkit that provides specialized agents, reusable workflows, and security scanning to optimize coding agent performance across multiple development harnesses.

### Key Points
- ECC supports major coding agents including Claude Code, Codex, Cursor, Kimi Code, and GitHub Copilot.
- The toolkit includes 68 specialized agents, 292 reusable skills, and 94 command shims for tasks like TDD, security, and architecture.
- Version 2.2.2 introduces a guided, manifest-driven setup wizard to manage installations, updates, and uninstalls safely.
- AgentShield provides integrated security auditing, including secret detection and adversarial risk assessment using Claude Opus.
- The system is MIT-licensed and available via GitHub, npm packages, and official marketplace plugins.

### Why it Matters
ECC standardizes agentic workflows by providing a consistent engineering toolbox that persists across different coding environments and sessions. By centralizing rules, memory, and security scanning, it helps developers reduce context window pressure and improve the reliability of autonomous coding tasks.
