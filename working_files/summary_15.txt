Claude Code Adds Cross-Session Messaging on macOS
============================================================

Anthropic has updated its Claude Code tool to version 2.1.224, enabling separate terminal sessions to communicate directly with each other to streamline complex development workflows on macOS and Linux.

### Key Points
- The update introduces ListAgents and SendMessage tools, allowing active terminal sessions to exchange text-based information without manual copy-pasting.
- Received messages appear as labeled cards with links, ensuring users can track context between different tasks or dependencies.
- Security protocols restrict shared data to text only, excluding file access, conversation history, or permission-granting capabilities.
- Local messaging between sessions on the same machine remains private and does not transmit data to Anthropic’s servers.
- The feature is currently limited to macOS and Linux, with cross-machine communication supported only via the Remote Control feature for mobile apps.

### Why it Matters
This update improves developer productivity by reducing the friction of managing multiple, disconnected coding environments. By allowing autonomous sessions to coordinate, Anthropic is lowering the overhead required for complex, multi-part software engineering projects.
