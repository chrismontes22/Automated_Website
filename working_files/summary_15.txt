GitHub has not removed malicious imitation software after 3 weeks
============================================================

The developer of Easy Data Transform reports that GitHub took over three weeks to remove a malicious repository impersonating their software after public pressure mounted on social media.

### Key Points
- The developer discovered an unauthorized repository on GitHub using the Easy Data Transform name and logo on August 31.
- Security analysis of the repository's Mac .dmg file revealed multiple malware warnings and modified installation instructions designed to bypass user security alerts.
- The developer submitted reports to GitHub on August 31 and September 10 but received no human response for 23 days.
- GitHub removed the malicious repository on September 24, shortly after the developer’s complaint gained significant traction on the Hacker News front page.

### Why it Matters
This incident highlights significant concerns regarding the responsiveness of major hosting platforms when addressing security threats and intellectual property infringement. It underscores the potential risks users face when downloading software from unofficial sources and suggests that public visibility is often required to expedite platform moderation.
