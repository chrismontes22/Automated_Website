Hackers Exploit Plex2Shell Flaws to Install Crypto Miners and Linux Proxy Backdoor
============================================================

Threat actors are actively exploiting a chain of four vulnerabilities, collectively known as Plex2Shell, to deploy cryptocurrency miners and reverse proxy software on vulnerable Plex Media Server instances.

### Key Points
- The Plex2Shell exploit chain allows unauthenticated remote code execution by chaining four vulnerabilities, including CVE-2026-96656, which carries a high CVSS score of 8.6.
- Security researcher Zach Main disclosed the flaws on July 27, 2026, and Plex released a patch in version 1.43.3.10861 on August 3, 2026.
- Attackers are using the exploit to install the "mylovelyminer" XMRig payload and a Linux backdoor identified as "myawesomeproxy."
- Malicious activity has been traced to several IP addresses, including 91.92.40.202 and 45.194.92.222, following the public release of proof-of-concept code on October 16, 2026.
- Users are urged to update their Plex installations immediately to mitigate the risk of unauthorized remote access and resource hijacking.

### Why it Matters
This exploit chain poses a significant security risk to home media server users by enabling attackers to gain full control over compromised systems. Promptly updating software is essential to prevent the unauthorized deployment of botnet-related proxies and cryptocurrency mining operations that can degrade system performance and compromise network security.
