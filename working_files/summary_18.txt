Canonical adds FIDO2 hardware key support to Launchpad
============================================================

Canonical has introduced hardware-bound FIDO2 security key support for Launchpad, allowing developers to secure API access and prevent unauthorized use of stolen login tokens for Ubuntu package management.

### Key Points
- Launchpad now supports USB FIDO2 security keys to protect developer API access and prevent credential theft.
- The new system replaces static stored tokens with long-lived OAuth refresh grants tied to physical hardware.
- Users must touch their security key and enter a PIN to generate short-lived tokens for daily operations.
- The feature currently supports only USB-based keys and requires the installation of the python3-fido2 package.
- This security update specifically targets core distribution engineers and package uploaders who manage sensitive system infrastructure.

### Why it Matters
This update significantly hardens the security of the Ubuntu ecosystem by mitigating the risk of malware hijacking developer credentials. By requiring physical hardware authentication, Canonical reduces the potential for supply chain attacks that could compromise critical software packages.
