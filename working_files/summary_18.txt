Malicious npm Package indexed-btree Hid Its Loader in Runtime Code Before Removal
============================================================

The malicious npm package indexed-btree has bypassed new security controls by executing obfuscated code at runtime rather than during installation, resulting in significant illicit cryptocurrency profits for attackers.

### Key Points
- The indexed-btree package, which mimicked a legitimate utility, generated approximately €230,933 in Ethereum by exploiting runtime execution.
- Attackers shifted tactics after npm version 12 restricted automatic lifecycle script execution, moving malicious payloads directly into application code methods.
- The malware used the EtherHiding technique to retrieve encrypted payloads from a smart contract on the Sepolia testnet.
- Checkmarx identified ten additional malicious packages linked to the same operation, all of which have been removed from the npm registry.
- A separate campaign, PolinRider, is currently compromising developer accounts on Packagist to inject malicious code into legitimate software repositories.

### Why it Matters
This shift demonstrates that attackers are rapidly evolving their methods to circumvent supply chain security improvements by moving malicious activity from installation hooks to runtime execution. Organizations must now implement layered defense strategies, including runtime behavior analysis, to detect threats that bypass traditional static installation-time security controls.
