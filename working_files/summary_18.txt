2CLoader: A New Malware Loader Delivering Vidar and Remus
============================================================

Zscaler ThreatLabz has identified 2CLoader, a sophisticated new malware loader discovered in August 2026 that employs advanced evasion techniques to distribute information stealers like Vidar and Remus.

### Key Points
- 2CLoader utilizes indirect system calls and inline trampoline hooks to bypass endpoint security detection.
- The loader features extensive anti-analysis capabilities, including anti-VM, anti-debug, and user activity checks.
- It supports multiple persistence mechanisms, such as scheduled tasks, registry run keys, and startup folder placement.
- Payloads are decrypted using AES-GCM and Xpress Huffman decompression, with configuration-based execution options like RunPE and CLR hosting.
- The malware communicates via HTTP, using JSON-formatted messages to report system information and execution status to its command-and-control server.

### Why it Matters
- The emergence of 2CLoader highlights a growing trend in highly customizable, evasive malware designed to facilitate the deployment of credential-stealing threats. By effectively bypassing traditional security controls, this loader increases the risk of data exfiltration and subsequent large-scale cyberattacks against organizations.
