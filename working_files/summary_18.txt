MacSync info-stealing malware hides malicious commands in an iCloud calendar
============================================================

A new variant of the MacSync infostealer is targeting macOS users by hiding malicious commands within public iCloud calendars to deliver persistent backdoors and steal sensitive data.

### Key Points
- Kaspersky researchers discovered the malware spreading through a fake cryptocurrency wallet application named Toria, promoted via X and Telegram.
- The malware uses advanced techniques, including binary droppers and loaders written in Swift and Objective-C, to bypass traditional security measures.
- Attackers utilize public iCloud calendar events to host malicious commands that download secondary payloads onto the victim's device.
- The stealer harvests browser data, crypto wallet information, Keychain files, and configuration files for development tools like AWS, Kubernetes, and Git.
- A persistent backdoor disguised as the macOS Finder process allows attackers to execute remote commands and potentially intercept browser traffic.
- The malware employs the Pluggable Authentication Modules (PAM) API to capture administrator passwords, a technique rarely seen in previous macOS threats.

### Why it Matters
This sophisticated campaign highlights an evolving threat landscape where attackers leverage legitimate cloud infrastructure to bypass security filters and maintain persistence. By specifically targeting developers and cryptocurrency users, the MacSync malware poses a significant risk to both individual assets and broader corporate supply chain security.
