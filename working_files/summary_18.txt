This Tiny USB Device Turns Your Phone Into a Keyboard, Mouse, and SSH Terminal
============================================================

TechxArtisan has launched the Openterface KeyMod on CrowdSupply, a versatile USB-bridge device that allows users to control computers and manage headless servers directly from their smartphones.

### Key Points
- The device functions as a composite USB keyboard, mouse, and network bridge, enabling SSH access and file transfers without requiring existing Wi-Fi or DHCP configurations.
- It features a WCH CH32V208 RISC-V microcontroller and supports BLE 5.3, with the "Plus" model offering an additional wired USB connection for higher bandwidth.
- The KeyCmd app provides advanced features including macro scripting, gamepad emulation, and an experimental AI agent mode for executing terminal commands via LLMs.
- Hardware is available in two variants, Mini (USB-C) and Plus (USB-A), both priced at $42 with an estimated shipping date of February 14, 2027.
- The project is slated to become fully open source, with plans for OSHWA certification and future firmware updates to enable AES-128 Bluetooth encryption.

### Why it Matters
This tool simplifies remote server management and hardware troubleshooting by eliminating the need for dedicated peripherals or complex network setups. By providing low-level access to BIOS and recovery environments via a smartphone, it offers a portable, efficient solution for IT professionals and Linux enthusiasts.
