Meta Is Challenging Claude Code and Codex With New Muse Code
============================================================

Meta has launched Muse Code, an agentic coding tool powered by the new Meta Muse Spark 1.2 model, designed to help developers automate complex software engineering and debugging tasks.

### Key Points
- Muse Code utilizes autonomous agents to execute background coding tasks, including website and application development.
- The underlying Meta Muse Spark 1.2 model features specific improvements in code generation and codebase comprehension over the previous 1.1 version.
- Access is currently restricted to developers via Meta’s official website and the OpenRouter platform using an API key.
- Pricing for the Spark 1.2 model is set at $1.25 per million input tokens and $4.25 per million output tokens.

### Why it Matters
This release positions Meta as a direct competitor to established agentic coding tools like OpenAI’s Codex and Anthropic’s Claude Code. By lowering the barrier for autonomous software development, Meta is accelerating the trend of "vibe coding" while forcing businesses to carefully manage the rising costs of high-volume AI token usage.
