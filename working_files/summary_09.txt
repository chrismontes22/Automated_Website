WhatsApp's Scam Alert feature is now available to beta users on Android
============================================================

WhatsApp has begun testing a new Scam Alert feature for Android beta users, designed to identify and warn recipients about potential fraudulent messages from unknown senders.

### Key Points
- The feature is currently available to Android users enrolled in the WhatsApp beta program via version 2.26.34.1.
- Scam Alert utilizes on-device machine learning to detect suspicious messages without compromising end-to-end encryption.
- Users must manually enable the optional tool through the Settings and Account menu within the application.
- Recipients can choose to mark a sender as trusted, block the contact, or report the interaction to WhatsApp.
- Meta confirmed that message content remains on the device and is not shared with the company for classification purposes.

### Why it Matters
This feature provides a critical layer of security for WhatsApp’s billions of users by proactively identifying potential fraud without sacrificing privacy. By keeping the machine learning model on-device, Meta balances user safety with its commitment to end-to-end encryption, potentially reducing the prevalence of phishing and spam on the platform.
