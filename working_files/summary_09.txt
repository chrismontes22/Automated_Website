assemblyline 4.7.5.dev121
============================================================

The Assemblyline 4 framework update introduces essential libraries and data management components, requiring Python 3.11 and Linux-based environments for optimal performance and system compatibility across all deployments.

### Key Points
- Assemblyline 4 requires Python 3.11 and is officially tested exclusively on Linux operating systems.
- The repository provides core infrastructure components including cachestore, datastore, filestore, ODM, and remote data types.
- Required Linux dependencies include libffi8, libfuzzy2, libmagic1, and python3.11-dev for manual installations.
- Users can bypass manual library installation by utilizing the official cccs/assemblyline container image.
- Version 4.7.5.dev121 is now available as a source distribution package with a file size of 851.0 kB.

### Why it Matters
- These updates ensure that developers maintain a stable and secure environment for the Assemblyline malware analysis platform. By standardizing on Python 3.11 and containerized deployments, the team simplifies dependency management and improves cross-system reliability.
