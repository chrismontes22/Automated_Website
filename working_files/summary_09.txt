WeaselBiscuit Stealer Spreads via 13 npm Packages to Harvest Chrome Extension Storage
============================================================

Cybersecurity researchers have identified 13 malicious npm packages distributing a new, lightweight JavaScript stealer named WeaselBiscuit that shares functional similarities with North Korean-linked malware strains.

### Key Points
- Researchers discovered 13 malicious npm packages, including "@biz44/id10-client" and "process-tailwind," used to deploy the WeaselBiscuit malware.
- WeaselBiscuit is a stripped-down information stealer that harvests Chrome extension data, clipboard contents, and keystrokes from Windows, macOS, and Linux systems.
- The malware executes in memory after being triggered by an npm import, pulling its configuration from Npoint JSON storage services.
- While the tool shares code and architectural similarities with the DPRK-linked BeaverTail and OtterCookie malware, researchers have not yet confirmed a definitive North Korean attribution.
- The malware uses numerical campaign IDs to track installations, a tactic previously observed in other campaigns like PolinRider.

### Why it Matters
This discovery highlights the ongoing risk of supply chain attacks targeting software developers through compromised open-source repositories. By harvesting sensitive data from browser extensions, this lightweight malware poses a significant threat to users' financial information and digital credentials.
