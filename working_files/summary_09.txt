Credential-Stealing GitHub Actions Workflows Planted in Tens of Thousands of Repositories
============================================================

The GhostAction supply chain campaign has compromised high-profile GitHub maintainer accounts to inject malicious workflows, resulting in the theft of thousands of sensitive credentials from numerous repositories.

### Key Points
- Attackers compromised accounts belonging to Takashi Kitao and Henry Wu to push malicious "security-audit.yml" workflows into over 340 repositories.
- The campaign has impacted 817 repositories and 327 GitHub users, leading to the exfiltration of 3,325 secrets including AWS, OpenAI, and npm tokens.
- Malicious workflows scan entire git histories and working trees for 13 credential patterns, exfiltrating data to a hard-coded IP address via plain HTTP.
- Security researchers identified over 500 GitHub accounts involved in the campaign, which has been active since September 2025.
- Developers are urged to rotate all credentials, delete malicious workflow files from all branches, and audit downstream forks for potential exposure.

### Why it Matters
This campaign highlights a critical vulnerability in the software supply chain where compromised maintainer credentials can be leveraged to automate large-scale data theft across thousands of projects. Organizations must prioritize rotating secrets and auditing CI/CD workflows to prevent unauthorized access to cloud, AI, and SaaS infrastructure.
