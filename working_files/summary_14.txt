Hackers breach Microsoft 365 tenants via ConnectWise supply-chain attack
============================================================

ConnectWise has suspended its Cloud Backup service after hackers exploited application identities to gain unauthorized access to numerous Microsoft 365 tenants, prompting an urgent security investigation.

### Key Points
- ConnectWise disabled seven application identities after identifying unauthorized access to its Cloud Backup service starting October 15.
- Cybersecurity firms Huntress and Todyl confirmed at least 162 compromised Microsoft 365 tenants linked to a single malicious IP address.
- Attackers abused existing service principal permissions to perform reconnaissance, escalate privileges, and establish persistence within customer environments.
- The breach bypassed multi-factor authentication because the attackers used automated scripts to authenticate directly as the backup application.
- ConnectWise maintains that stored backup archives remain encrypted and isolated, with no current evidence of data compromise.

### Why it Matters
This incident highlights the significant risks associated with supply-chain attacks where third-party software providers serve as a gateway into highly privileged customer environments. Because these applications often hold broad permissions, a single compromise can allow attackers to bypass standard security measures like multi-factor authentication and gain deep access to sensitive corporate data.
