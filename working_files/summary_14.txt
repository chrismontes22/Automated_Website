Other users can watch your browsing and time your keystrokes through OS file notifications
============================================================

Researchers at Graz University of Technology discovered that unprivileged accounts can monitor system-wide file notifications to track user activity, including browsing history, keystroke timing, and application usage patterns.

### Key Points
- Attackers use native file-notification systems like Windows ReadDirectoryChangesW, Linux inotify, and macOS FSEvents to monitor activity across different user accounts.
- On Windows, researchers successfully identified 95.7% of websites visited in Firefox by tracking folder creation events, even within restricted user directories.
- Linux systems are vulnerable to keystroke timing attacks, allowing observers to reconstruct typed text by monitoring device file events during local or SSH sessions.
- Android 16 devices were found to leak private data, including photos and WhatsApp media, through the FileObserver API despite scoped storage protections.
- Microsoft introduced a registry policy in update KB5058189 to mitigate these leaks, though the feature remains disabled by default on standard installations.
- Linux kernel developers released a partial patch in 2026, tracked as CVE-2025-68788, to restrict access to device file notifications.

### Why it Matters
These findings highlight a fundamental design flaw in how modern operating systems handle file-system event notifications, potentially allowing malicious software to spy on other users without elevated privileges. Because these vulnerabilities rely on standard system features, they pose a significant privacy risk that requires OS-level architectural changes rather than simple application-layer fixes.
