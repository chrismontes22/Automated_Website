Cancelling Cursor
============================================================

Longtime users are increasingly canceling their Cursor subscriptions due to persistent software bugs, outdated VSCode base versions, and a perceived shift away from core IDE functionality.

### Key Points
- Cursor consistently runs on a VSCode build that is seven to nine months behind the current release, causing frequent extension compatibility issues.
- Users report persistent UI bugs, including an "Agent" view that resets to default upon restart and poorly formatted settings menus.
- Community feedback on official forums and Reddit is reportedly being ignored or deleted by moderators despite significant user engagement.
- The platform is shifting its focus toward enterprise-grade agentic workflows, moving away from the code-first experience that originally defined the product.
- Developers are increasingly opting for standard VSCode or alternative AI coding tools that offer more stability and direct access to underlying models.

### Why it Matters
The decline in user satisfaction highlights a growing tension between specialized AI coding tools and the need for a stable, reliable development environment. As Cursor pivots toward enterprise agent services, it risks alienating its core base of professional developers who prioritize IDE performance and consistent software maintenance.
