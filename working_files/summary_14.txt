CrowdSec Says TanStack npm Attack Led to Copy of 170 Private GitHub Repositories
============================================================

CrowdSec confirmed that an attacker accessed 170 private GitHub repositories in May after compromising a former employee's credentials through a supply chain attack on TanStack npm packages.

### Key Points
- An attacker used a stolen GitHub OAuth token to copy private repositories on May 22, 2024.
- The breach exposed 83 user email addresses and personal details of 51 investors from 2020.
- Compromised code included internal data science models, automation scripts, and consensus algorithm thresholds.
- The incident originated from a supply chain attack on TanStack (CVE-2026-45321) that stole developer credentials.
- CrowdSec confirmed its core infrastructure, databases, and public Security Engine remained unaffected by the unauthorized access.
- The company has since rotated all exposed credentials and implemented mandatory endpoint protection for developer devices.

### Why it Matters
This incident highlights the significant risks posed by supply chain attacks where malicious dependencies can bypass traditional security perimeters by stealing developer credentials. It serves as a critical reminder for organizations to strictly manage offboarding processes and revoke access for former employees immediately to prevent long-term vulnerabilities.
