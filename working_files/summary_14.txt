Sanctioned billion-dollar cybersecurity company from Russia finds 11 vulnerabilities in Google and Apple products — including a nasty one that compromised a device just through a malicious NFC tag
============================================================

Russian cybersecurity firm Positive Technologies identified 11 high-severity security vulnerabilities affecting Apple and Android devices, prompting both companies to release software patches to address the identified flaws.

### Key Points
- Positive Technologies reported nine vulnerabilities in Apple software and two in Android, including issues affecting Google Pixel devices.
- One Android flaw allowed malicious NFC tags to install and execute apps without user consent, while another permitted unauthorized changes to Wi-Fi and network settings.
- Apple vulnerabilities included a macOS flaw granting attackers root-level system privileges and a kernel issue capable of causing data corruption or system failure.
- Google addressed the Android security gaps in its September 2026 software updates.
- Apple has issued patches for its affected operating systems, though specific version details remain undisclosed.

### Why it Matters
These vulnerabilities highlight the ongoing risks posed by unpatched software, particularly for older devices that no longer receive security updates from manufacturers. Users should verify that their devices are running the latest available software versions to protect against potential unauthorized access and data exploitation.
