7-Zip has a hidden security tool I somehow never noticed
============================================================

7-Zip users can verify file integrity by using the built-in CRC SHA tool to compare downloaded file hashes against developer-provided values, ensuring files remain uncorrupted and unaltered.

### Key Points
- The 7-Zip context menu allows users to calculate SHA-256 and other hash types without installing additional software.
- A hash match confirms that a downloaded file is identical to the reference provided by the publisher.
- Hash verification detects file corruption or unauthorized modifications that file size and name checks cannot identify.
- Users should prioritize verifying high-risk files, such as operating system images, installers, and firmware, before execution.
- A successful hash match only confirms the file matches the provided reference, not that the source itself is inherently trustworthy.

### Why it Matters
Verifying file integrity is a critical security habit that prevents users from executing corrupted or malicious software. By utilizing existing tools like 7-Zip, users can easily mitigate risks associated with software downloads without needing specialized third-party applications.
