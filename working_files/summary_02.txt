Secure temporary file sharing for AI agents and humans
============================================================

Aispace.sh provides an open-source, scriptable command-line interface designed for secure, temporary file sharing between AI agents and human users through automated, machine-readable workflows and encrypted storage.

### Key Points
- Supports automated file uploads via CLI with stable JSON output, streaming, and predictable exit codes for integration into agent scripts.
- Features configurable security controls including file expiration, download caps, and optional local-only encryption using the age X25519 protocol.
- Offers specialized commands for sealed transfers, device pairing, and authenticated handoffs between specific agent identities.
- Provides cross-platform support for macOS, Linux, and Windows via binary releases, Homebrew, npm, and Go installation methods.
- Operates as a client-side tool that keeps master encryption keys local, ensuring the hosted service does not access private file content.

### Why it Matters
This tool addresses the growing need for reliable data exchange between autonomous AI agents and human-managed systems by providing a standardized, bot-friendly interface. By automating the secure transfer of large or temporary artifacts, it enables more complex agent workflows while maintaining strict privacy and data lifecycle management.
