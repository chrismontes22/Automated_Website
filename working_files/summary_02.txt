OpenAI’s new ChatGPT feature logs your keystrokes and stores them in plain text
============================================================

OpenAI has introduced a new macOS feature called Computer History that logs user clicks, keystrokes, and app activity to create a searchable memory for the ChatGPT assistant.

### Key Points
- The feature records keyboard shortcuts, clicks, and app switches via the macOS accessibility framework but excludes screenshots, audio, and private browsing data.
- Recorded event files are stored locally as unencrypted plain-text Markdown files, making them potentially accessible to other programs running under the same user account.
- Temporary event logs are deleted after 48 hours, and OpenAI states that these raw files are not used to train its artificial intelligence models.
- Administrators must enable the feature for Business and Enterprise accounts, and individual users retain the ability to pause recording or exclude specific apps and websites.
- The tool is currently unavailable to users located in the European Economic Area, Switzerland, and the United Kingdom.

### Why it Matters
This feature represents a significant shift in how AI assistants gather contextual data by prioritizing text-based input events over visual screen captures. While it offers enhanced productivity through searchable history, the lack of local file encryption and potential privacy risks regarding sensitive data necessitate careful user management.
