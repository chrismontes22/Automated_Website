Parley: Federated, decentralised chat that speaks plain IRC
============================================================

The Fastidious chat platform has released a fix for a bug that allowed users to join invalid channels, preventing persistent connection errors and unauthorized room creation.

### Key Points
- The update prevents users from joining channels that lack the required `#` or `&` prefixes, returning a 403 error instead.
- Previously, invalid channel joins created global rooms that caused repeated federation errors and prevented proper direct messaging.
- The patch automatically cleans up existing invalid memberships from `members.json` upon system restart.
- New automated tests, including `TestJoinRefusesANameThatIsNotAChannel`, ensure that invalid join attempts are rejected before any data is stored.
- Documentation in `PROTOCOL.md` has been updated to clarify channel naming requirements for the platform.

### Why it Matters
This fix improves network stability by eliminating unnecessary federation traffic caused by persistent, invalid join requests. It also ensures a more consistent user experience by preventing the creation of broken, non-functional chat rooms.
