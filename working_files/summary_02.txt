Fake iPhone Duo preorder page can steal crypto wallet data and more
============================================================

Security researchers at Malwarebytes have identified a malicious website impersonating an official Apple store that uses the DarkSword exploit to compromise unpatched iPhones via a drive-by download.

### Key Points
- The fraudulent website lures users with a fake $500 discount voucher ahead of the official iPhone Duo pre-order date on October 16.
- Simply visiting the site triggers the DarkSword exploit chain, which targets vulnerabilities in older, unpatched versions of iOS.
- Once a device is compromised, the malware attempts to steal cryptocurrency wallet data, saved keychain credentials, and personal information like messages and contacts.
- The exploit chain was originally disclosed by Google in March, and Apple released a security patch to address the vulnerability later that same month.

### Why it Matters
This attack highlights the critical importance of keeping mobile devices updated with the latest security patches to defend against known exploit chains. Users should exercise extreme caution with unsolicited links, as drive-by attacks can compromise sensitive financial and personal data without requiring any user interaction.
