A barely working Android phone screen didn't stop me from building a functional home server
============================================================

Repurposing an old Android smartphone with a damaged display into a functional home server is possible by utilizing ADB tools and virtualization software to bypass hardware limitations.

### Key Points
- Use the scrcpy tool to mirror a damaged Android screen to a PC, allowing for navigation via mouse and keyboard.
- Enable USB debugging immediately if a phone screen shows signs of failure to ensure future access to the device.
- Utilize the Universal Android Debloater to remove unnecessary apps and free up storage space for server tasks.
- Deploy Podroid to run an Alpine Linux virtual machine and Docker containers, which is more efficient than standard Termux setups.
- Allocate specific hardware resources, such as 2GB of RAM and 4 CPU cores, to maintain system stability on older devices.
- Run lightweight, client-side applications like BentoPDF and OmniTools to maximize the limited processing power of repurposed hardware.

### Why it Matters
Converting discarded smartphones into home servers reduces electronic waste while providing a cost-effective way to host lightweight applications. This process demonstrates how specialized software tools can extend the lifecycle of hardware that would otherwise be considered unusable due to physical damage.
