GitHub package firewall
============================================================

GitHub has launched a new package firewall in public preview to protect enterprise CI runners and coding agents from malicious software during the automated dependency installation process.

### Key Points
- The firewall acts as a policy gate, inspecting metadata and package downloads for malicious activity before they reach internal systems.
- Administrators can configure security controls, including cooldown periods, GitHub Advisory Database checks, and supply-chain attestation verification.
- The service is currently available to all GitHub Enterprise Cloud customers at no cost during the public preview period.
- Initial support is limited exclusively to npm packages, with plans to scale infrastructure and features based on user demand.
- Blocked packages can be appealed through an exception request workflow similar to existing GitHub Advanced Security features.

### Why it Matters
This security layer addresses critical vulnerabilities in automated build environments where human oversight is often absent during dependency installation. By centralizing policy enforcement, organizations can significantly reduce the risk of supply-chain attacks infiltrating their development pipelines.
