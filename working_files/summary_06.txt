AliceLabs LLC has launched a new marketplace featuring over 9,200 Model Context Protocol (MCP) servers designed to integrate custom capabilities into AI agents like Claude Desktop and Cursor.

### Key Points
- The platform offers 9,248 MCP servers compatible with tools including Cursor, Cline, Continue, and Aider.
- Users can install skills via the command line using the `npx -y @marketnow/install` command.
- Security is managed through Sentinel L2.5 audits utilizing gVisor sandboxing for all listed servers.
- The directory includes 43 free, hand-curated skills that require no signup or payment to access.
- Founded in 2024 by Edison Flores, the project operates as an independent, bootstrapped entity based in Wyoming.
- The marketplace supports five languages and provides a public JSON API for machine-readable access.

### Why it Matters
This marketplace simplifies the expansion of AI agent capabilities by providing a centralized, searchable registry for Model Context Protocol integrations. By standardizing installation and security auditing, it lowers the barrier for developers to enhance their AI workflows with verified, ready-to-use tools.
