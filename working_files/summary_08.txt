Laser is a new, modern CD ripper for Linux
============================================================

Laser is a new GTK4-based CD ripping application for Linux that offers a modern interface and support for multiple audio formats to help users digitize physical music collections.

### Key Points
- Laser is available for installation via Flathub and utilizes the libadwaita library for a modern desktop aesthetic.
- The software automatically retrieves track metadata and cover art from online sources, allowing users to embed images directly into files.
- Supported output formats include FLAC, MP3, AAC, Opus, and WAV, with options to archive discs as single image files with CUE sheets.
- Users can customize folder structures and edit track titles before extraction, though the current version requires ripping the entire disc rather than selecting individual tracks.

### Why it Matters
As physical CD sales experience a resurgence among younger consumers, modern software tools are necessary to bridge the gap between legacy media and contemporary digital music libraries. This application provides Linux users with a streamlined, updated alternative to aging tools for archiving physical collections onto local media servers.
