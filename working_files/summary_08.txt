Surveillance Camera Security? It’s Completely Flocked!
============================================================

Security researcher Micah Lee has identified critical vulnerabilities in Flock Safety surveillance cameras, including the use of outdated Android software and exposed hard-coded API keys for law enforcement.

### Key Points
- Flock Safety cameras currently run on Android 8.1, an unsupported operating system version released in 2017 that contains numerous unpatched security vulnerabilities.
- Researchers discovered a hard-coded, open-access API key that allows unauthorized users to retrieve data from any camera by using its unique MAC address.
- The findings raise significant concerns regarding the privacy and security standards of surveillance technology deployed by law enforcement agencies.
- The company faces technical challenges in remediating these flaws, as it remains unclear if they can deactivate the leaked key without disrupting the entire camera network.

### Why it Matters
These security lapses expose sensitive surveillance data to potential exploitation by unauthorized actors, undermining the reliability of tools used by law enforcement. The incident highlights the broader risks associated with deploying internet-connected hardware that lacks rigorous software maintenance and secure authentication protocols.
