This tiny Android browser punches way above its weight
============================================================

The new open-source Eddy browser for Android offers a lightweight, privacy-focused alternative to mainstream apps by utilizing the system WebView to maintain a minimal 3.5MB installation size.

### Key Points
- Eddy is built with Kotlin and Jetpack Compose, featuring a Material 3 Expressive interface designed for one-handed navigation.
- The browser maintains a small footprint by leveraging Android’s system WebView rather than shipping a standalone rendering engine.
- Privacy features include host-based ad blocking, an encrypted AES-256-GCM password manager, and a secure incognito mode using separate WebView profiles.
- Memory management is optimized by limiting active tabs to four, automatically saving and rebuilding older tabs to preserve system resources.
- The application is currently in beta, free to use, and does not track user data or display advertisements.

### Why it Matters
Eddy demonstrates how modern development tools can create highly efficient, privacy-centric alternatives to bloated mobile browsers. Its success highlights a growing market demand for lightweight software that prioritizes user control and hardware performance over data-heavy features.
