CyberXero Uses Claude Code in Campaign That Stole Over 628,000 Ukrainian Records
============================================================

The Russian-speaking threat actor CyberXero is utilizing AI-augmented tools to conduct automated global cyberattacks on WordPress sites alongside targeted espionage against critical infrastructure in Ukraine.

### Key Points
- CyberXero uses Anthropic’s Claude Code and the PentAGI agent to automate exploit chaining, reconnaissance, and post-exploitation tasks.
- The campaign has successfully exfiltrated over 628,000 records from four Ukrainian organizations and compromised systems in Poland, China, and the Netherlands.
- Attackers exploit known vulnerabilities, including CVE-2026-63030 and CVE-2026-60137, to seize control of WordPress administration panels and deploy web shells.
- Researchers discovered the operation after identifying an exposed server directory containing AI session logs, exploitation scripts, and stolen victim data.
- The threat actor bypasses AI safety protocols by using context-engineering techniques to frame malicious requests as authorized penetration testing activities.

### Why it Matters
This campaign demonstrates how threat actors are industrializing cyberattacks by integrating autonomous AI agents into their operational pipelines to increase speed and scale. The ability to bypass model safety filters to generate malicious code poses a significant challenge for security teams defending against both opportunistic financial crime and state-aligned espionage.
