Adobe Photoshop adds optional ‘AI Assisted Editor’ mode for fully prompt-based image editing
============================================================

Adobe has launched a beta version of its AI Assisted Editor for Photoshop, introducing a simplified, prompt-based interface designed to streamline complex image editing tasks for all users.

### Key Points
- The AI Assisted Editor features tools like Generative Fill, Generative Expand, and a new Markup tool for natural-language image adjustments.
- Users can toggle the simplified interface on or off via the Photoshop menu bar to switch between automated and traditional editing workflows.
- New prompt-based masked edits allow for precise, localized adjustments using the Firefly Image 5 model to maintain lighting and angle consistency.
- A non-destructive layer tool now provides Camera Raw-level adjustments for exposure, contrast, and shadows directly within the standard Photoshop workflow.
- The update includes Dynamic Text for custom shapes and a new dockable Adobe Stock panel providing access to over 900 million assets.

### Why it Matters
This update significantly lowers the barrier to entry for professional-grade image editing by integrating generative AI directly into the standard Photoshop interface. By offering both automated and manual workflows, Adobe is positioning its software to remain competitive as creative tools increasingly shift toward natural-language processing.
