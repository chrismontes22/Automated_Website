One Windows setting helped me spot a fake PDF before I opened it
============================================================

Enabling the File name extensions setting in Windows File Explorer helps users identify malicious executable files disguised as legitimate PDF documents, preventing potential cyberattacks and unauthorized software installations.

### Key Points
- Windows hides file extensions by default, allowing attackers to mask malicious .exe files as harmless PDF documents.
- Users can reveal true file types by selecting "File name extensions" under the "View" menu in File Explorer.
- Malicious files often use deceptive names like "Invoice.pdf.exe" to trick users into executing harmful programs.
- Security experts recommend avoiding files ending in .exe, .msi, .bat, .cmd, or .scr unless the source is verified.
- Enabling this setting is a simple, no-cost habit that adds a critical layer of visibility to basic Windows security.

### Why it Matters
This simple configuration change provides an immediate visual defense against common phishing tactics that rely on user oversight. By exposing hidden file extensions, users can verify the true nature of attachments before opening them, significantly reducing the risk of accidental malware infection.
