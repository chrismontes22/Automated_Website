GrapheneOS' rewritten Messages app is released
============================================================

The release of version 13 for this messaging application introduces a complete interface overhaul using Jetpack Compose and Material 3, alongside significant performance, security, and usability enhancements.

### Key Points
- Rebuilt the entire interface using Jetpack Compose and Material 3, featuring a new two-pane layout for large screens.
- Added advanced conversation controls, including message pinning, snooze options, and improved multi-select actions for archiving or deletion.
- Enhanced media and attachment handling with a redesigned picker, improved audio recording, and a rewritten photo viewer.
- Strengthened security through stricter shared-content validation, updated privacy settings, and the implementation of immutable pending intents.
- Updated platform requirements to target Android SDK 37, incorporating modern dependencies like Kotlin 2.4.10 and CameraX.

### Why it Matters
This comprehensive update modernizes the application's architecture to improve stability and provide a more responsive user experience across diverse Android devices. By prioritizing security and accessibility, the developers ensure the platform remains a reliable and compliant tool for modern mobile communication.
