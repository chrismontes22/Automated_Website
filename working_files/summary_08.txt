mssPortable 1.457.164 (Microsoft Safety Scanner antivirus launcher) Released
============================================================

The latest version of mssPortable is now available, allowing users to run the Microsoft Safety Scanner as a portable application for detecting and removing malware on Windows systems.

### Key Points
- mssPortable enables the Microsoft Safety Scanner to run without requiring a full installation on a Windows computer.
- The tool is packaged in the PortableApps.com Format for seamless integration with the PortableApps.com Platform, Menu, and Backup Utility.
- Users can perform automatic updates or install the software directly through the PortableApps.com store.
- The scanner is free for personal use but requires a fresh download every 10 days to remain functional.
- Existing settings are preserved when upgrading the application over a previous installation.

### Why it Matters
This release provides a convenient, portable method for users to perform on-demand malware scans without altering their host operating system. It serves as a useful supplementary security tool for technicians and individuals who need to clean infected machines using trusted Microsoft software.
