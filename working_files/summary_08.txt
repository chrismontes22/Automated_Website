Android 17 beta tackles a security loophole thieves could exploit
============================================================

Google’s Android 17 QPR3 Beta 2 introduces a security feature requiring biometric or PIN authentication to toggle connectivity settings like Wi-Fi and mobile data from a locked screen.

### Key Points
- Users can now restrict access to Airplane Mode, Wi-Fi, Bluetooth, and Mobile Data tiles on the lock screen.
- Non-security features like Flashlight, Auto-rotate, and Battery Saver remain accessible without requiring device authentication.
- The update, released October 20 with build number DP11.261002.005, addresses system crashes, random reboots, and Bluetooth pairing failures.
- Fixes are included for high idle battery drain caused by motion sensors and connectivity issues on specific networks like Dish, IT&E, and OXIO.
- The feature is available for eligible Pixel devices enrolled in the Android Beta Program via the Security & privacy or Lock screen settings menus.

### Why it Matters
This update provides a critical security layer that prevents thieves from disabling network connectivity on stolen devices, which often hinders remote tracking capabilities. By requiring authentication for sensitive toggles, Google makes it significantly harder for unauthorized users to isolate a phone from the network.
