A Botnet Used Poetry To Mine Crypto From Over 3,000 Servers - Here's How
============================================================

Security researchers at Black Lotus Labs have identified a sophisticated botnet called PoeLLM that uses AI-generated poetry on GitHub to hide command-and-control instructions for cryptocurrency mining.

### Key Points
- The PoeLLM botnet has compromised over 3,400 servers, peaking at 800 active daily infections in June 2026.
- Malware uses a poem titled "On the Nature of Connection" to derive remote server addresses via a hardcoded word-to-number cipher.
- Primary targets include enterprise servers running vulnerable versions of open-source AI tools like Ollama, LiteLLM, and the PDF converter Gotenberg.
- Attackers update the poem on GitHub to dynamically redirect infected machines to new command-and-control infrastructure.
- Lumen Technologies reports that three of the twelve identified command-and-control IP addresses remain active.

### Why it Matters
This campaign highlights the growing security risks associated with decentralized, open-source AI infrastructure that often lacks robust API protections. It demonstrates how attackers are increasingly using creative, automated methods to bypass traditional detection and maintain persistent control over enterprise networks.
