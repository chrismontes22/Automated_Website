Windows Wrap: Even Microsoft's own XBOX team didn't want Windows 11
============================================================

Reports suggest internal friction between Microsoft’s Xbox and Windows teams regarding the operating system for the next-generation Project Helix console, which is now expected to launch in 2028.

### Key Points
- Reports claim an Xbox leader threatened to cancel a gaming handheld if forced to utilize the standard Windows 11 desktop operating system.
- Xbox CTO Scott Van Vliet publicly refuted claims of team conflict, stating that the Project Helix operating system is being built on Windows.
- Microsoft has historically utilized customized versions of Windows for console hardware, including the Xbox One and Xbox Series X|S.
- The next-generation Project Helix console has reportedly been delayed, with a new expected release window of 2028.
- Current gaming handhelds running Windows 11 often face criticism for poor out-of-the-box experiences and complex update requirements.

### Why it Matters
This shift indicates that Microsoft is moving away from using the standard Windows 11 desktop experience as the foundation for its future gaming hardware. By prioritizing a custom OS built on Windows rather than the full desktop version, the company aims to resolve long-standing performance and usability issues that currently hinder gaming handhelds and consoles.
