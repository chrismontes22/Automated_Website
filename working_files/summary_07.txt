PamStealer macOS Malware Adds Live C2 Payload Decryption and Multi-Layer Persistence
============================================================

Cybersecurity researchers at Jamf Threat Labs have identified a sophisticated new version of the PamStealer malware that uses server-side decryption to evade static analysis on macOS systems.

### Key Points
- The updated PamStealer malware now uses a server-side decryption chain, requiring a live key exchange to unwrap the malicious payload.
- Attackers are distributing the malware via a fake cryptocurrency wallet website, "wavel[.]app," which prompts users to download a malicious disk image.
- The malware employs multiple persistence mechanisms, including LaunchAgents and Git hooks, to ensure the infection remains active across sessions.
- The final stealer component is written in Swift and targets credentials from a wide range of browsers, including Chrome, Firefox, Arc, and Zen.
- A new "pkgunpack" utility manages the decryption process, making it impossible for security analysts to recover the payload without an active command-and-control connection.

### Why it Matters
This evolution in PamStealer demonstrates a significant shift toward infrastructure-dependent malware that complicates traditional security analysis. By tying payload decryption to server availability, attackers can effectively hide their malicious code from researchers and maintain tighter control over their operations.
