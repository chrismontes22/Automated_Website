I put Linux on Microsoft’s own hardware, and it somehow works so much better than Windows
============================================================

Installing Ultramarine Linux on an aging Microsoft Surface Pro 6 improves thermal performance and system responsiveness, offering a viable alternative to Windows for users with older, sluggish hardware.

### Key Points
- The linux-surface project provides a customized kernel and drivers to ensure compatibility between Microsoft hardware and various Linux distributions.
- Ultramarine Linux offers a pre-configured installation image that includes the necessary drivers and codecs for Surface devices, simplifying the setup process.
- Essential hardware, including the touchscreen, speakers, microphone, and Surface Pen, functions immediately upon installation without requiring manual terminal configuration.
- Users must disable Secure Boot and manage BitLocker encryption keys within the UEFI settings to successfully boot from external installation media.
- While performance is improved, the Windows Hello IR camera remains unsupported, and desktop environments like KDE Plasma lack the native tablet-mode optimizations found in Windows 11.

### Why it Matters
Transitioning older Surface devices to Linux can extend the hardware's lifespan by reducing thermal output and eliminating the performance lag often associated with aging Windows installations. While users may sacrifice specific proprietary features like Windows Hello, the improved system stability provides a practical solution for those looking to repurpose legacy tablets.
