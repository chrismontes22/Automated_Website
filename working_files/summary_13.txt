Amazon Route 53 Resolver DNS Firewall support for Palo Alto Networks Advanced DNS Security is now Generally Available (GA)
============================================================

Amazon Route 53 Resolver DNS Firewall now supports Palo Alto Networks Advanced DNS Security, enabling organizations to block malicious traffic directly within their AWS virtual private cloud environments.

### Key Points
- The integration is now generally available across all 32 AWS Regions where DNS Firewall is currently offered.
- Security teams can detect and block threats like phishing, malware, and command-and-control traffic without deploying additional firewall appliances.
- Administrators can manage Palo Alto Networks security rules directly through the Route 53 DNS Firewall console.
- Licenses can be shared across multiple organization accounts using AWS License Manager.
- Rule groups can be associated with VPCs via AWS Resource Access Manager, Route 53 Profiles, or AWS Firewall Manager.

### Why it Matters
This integration simplifies cloud security architecture by removing the need for complex network modifications or separate firewall deployments. It allows enterprises to maintain consistent threat protection across hybrid cloud environments while streamlining the management of security policies within the AWS ecosystem.
