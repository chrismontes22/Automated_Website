Brow6el: A full-featured web browser for the terminal using Chromium
============================================================

Brow6el is a full-featured terminal web browser powered by Chromium that enables users to navigate the modern web with graphics support via Sixel and Kitty protocols.

### Key Points
- Supports Sixel and Kitty graphics protocols for rendering web content directly within terminal emulators.
- Features Vim-style modal navigation, including standard, insert, visual, and mouse-emulation modes.
- Includes advanced tools like a JavaScript console, element inspector, bookmark manager, and user script injection.
- Offers configurable privacy settings, including temporary or persistent profiles and DNS-over-HTTPS support.
- Compatible with Linux distributions including Ubuntu, Debian, and Arch Linux, with build support for multiple terminal emulators.
- Migrated its primary development repository to Tangled to consolidate project hosting.

### Why it Matters
This browser bridges the gap between terminal-based workflows and modern web requirements by providing a functional, Chromium-based environment for power users. It offers a unique solution for developers and system administrators who prefer keyboard-centric navigation without sacrificing the ability to view complex, graphics-heavy websites.
