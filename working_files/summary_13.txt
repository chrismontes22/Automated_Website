LaunchOnSF restores website as StepDrainer attack spreads to 10 more sites
============================================================

Security firm Blockaid identified a widespread frontend attack using the StepDrainer malware to target at least 12 decentralized finance and token-launch websites between October 30 and 31, 2026.

### Key Points
- The StepDrainer malware-as-a-service toolkit was injected into website frontends to trigger fraudulent wallet-connection requests.
- Affected platforms included StonkFun, pickle.finance, echelon.market, origami.finance, and fluxbeam.xyz.
- Attackers compromised DNS and domain systems to display malicious prompts, though no smart contracts or private keys were breached.
- LaunchOnSF confirmed that StonkFun services were restored quickly with no reported loss of user funds.
- Security experts advise users who interacted with the compromised sites to revoke token permissions using tools like Revoke.cash.

### Why it Matters
This incident highlights the growing vulnerability of website frontends as a primary attack vector for harvesting unauthorized token approvals from unsuspecting users. It underscores the necessity for DeFi platforms to secure their domain infrastructure to prevent attackers from exploiting user trust in legitimate web addresses.
