Malicious npm packages evade install-script defenses at runtime
============================================================

A sophisticated npm malware campaign using the malicious indexed-btree package bypasses security defenses by executing hidden code during runtime rather than through traditional installation scripts.

### Key Points
- The indexed-btree package, which mimics the legitimate sorted-btree library, has reached 2 million weekly downloads.
- Attackers hide malicious loaders within the BTree.prototype.set() method to evade npm v12 security measures and static analysis tools.
- Once active, the malware exfiltrates system data via Slack and Telegram and retrieves command-and-control instructions from an Ethereum smart contract.
- Checkmarx identified nine additional malicious packages, including btree-core, which collectively amassed millions of downloads before being removed.
- Researchers linked the operation to a cryptocurrency wallet containing 109 ETH, though the source of these funds remains unconfirmed.

### Why it Matters
This campaign demonstrates a critical shift in supply chain attacks where malicious actors bypass automated installation-time security by embedding threats within standard application runtime behavior. Developers must move beyond static scanning and implement robust runtime behavioral analysis to protect their environments from these sophisticated, stealthy threats.
