Proton Drive’s new CLI brings encrypted cloud storage to scripts and servers
============================================================

Proton has launched a new Command Line Interface for its privacy-focused cloud storage service, enabling developers and power users to automate file management tasks directly through scripts.

### Key Points
- The Proton Drive CLI allows users to upload, download, and manage files on headless servers, NAS devices, and Raspberry Pis without a graphical interface.
- It supports automated workflows, including scheduled off-site backups and integration with build servers, using JSON output for structured data handling.
- The tool maintains Proton’s zero-knowledge, end-to-end encryption standards while securely managing credentials via system-level facilities like macOS Keychain or Windows Credential Manager.
- Developers can access the CLI and underlying SDK on GitHub to build custom integrations or inspect the source code for security verification.
- The software is available as a standalone binary, including a Linux x64 build compatible with older hardware lacking AVX2 support.

### Why it Matters
This release expands Proton Drive’s utility beyond standard desktop users by enabling seamless integration into professional development pipelines and automated home-server environments. By removing the need for a graphical interface, it allows businesses and power users to manage secure, encrypted cloud storage through existing command-line workflows.
