Fake Zoom installer hides macOS backdoor CloudSyncD
============================================================

Jamf Threat Labs discovered a new macOS malware called CloudSyncD, which disguises itself as a Zoom installer to steal user passwords and establish a persistent backdoor for attackers.

### Key Points
- The malware uses a fake Zoom installer that prompts users to bypass macOS Gatekeeper security settings.
- It captures user passwords, obfuscating them within a JSON file using hidden Unicode characters to evade detection.
- CloudSyncD attempts to execute payloads directly from memory to avoid disk writes, falling back to temporary files if blocked by System Integrity Protection.
- Once active, the implant communicates with command-and-control servers every 8 to 16 seconds to receive and execute arbitrary programs.
- Researchers identified the malware in mid-September, noting it was actively communicating with two live domains protected by Cloudflare.

### Why it Matters
This discovery highlights the evolving sophistication of macOS threats that leverage social engineering to bypass native security protections. By combining credential theft with a modular backdoor, attackers can maintain long-term access to compromised systems while remaining difficult for standard security tools to detect.
