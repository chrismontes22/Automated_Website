Ubuntu 26.10 drops Btrfs, XFS & ZFS /boot with Secure Boot
============================================================

Canonical has restricted supported filesystems for the GRUB bootloader in Ubuntu 26.10 when Secure Boot is enabled to minimize potential security vulnerabilities within the system's boot chain.

### Key Points
- Ubuntu 26.10 limits Secure Boot compatibility to ext4, FAT, ISO9660, and squashfs filesystems.
- Support for Btrfs, XFS, ZFS, LVM, LUKS, and RAID (excluding RAID1) is removed from the signed GRUB build.
- Canonical removed HFS+, Apple partition table support, and image loading to reduce the boot process attack surface.
- Users requiring complex boot configurations can continue using Ubuntu 26.04 LTS, which remains supported for several years.
- The changes only impact the boot path; these filesystems remain fully functional once the operating system has loaded.

### Why it Matters
This update prioritizes system security by reducing the number of parsers active during the early boot phase, which have historically been targets for bypass vulnerabilities. While most standard installations remain unaffected, users with custom partition layouts must verify their configurations to avoid boot failures after upgrading.
