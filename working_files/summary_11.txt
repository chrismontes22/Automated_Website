Firefox 157 released with ‘biggest visual refresh in years’
============================================================

Mozilla has released Firefox 157, featuring the new Nova theme, which introduces a modernized visual interface with rounded UI elements and improved customization options for desktop browser users.

### Key Points
- The Nova theme updates core UI elements like tabs, menus, and address bars with a rounder, more colorful aesthetic across Windows, macOS, and Linux.
- A new official compact mode reduces spacing in toolbars and menus, providing more screen real estate for web content on smaller displays.
- Firefox Suggests is now available in several European countries, displaying sponsored content and search suggestions directly within the address bar.
- Amazon has been removed as a built-in search engine, and the browser now supports hardware AV1 decoding for WebRTC video calls.
- Users can disable the Nova theme by toggling the `browser.nova.enabled` setting in the `about:config` menu.
- The update includes various security vulnerability patches and a permanent "+" icon on the New Tab page for easier shortcut management.

### Why it Matters
This visual refresh represents Mozilla's most significant design overhaul in years, signaling a shift toward a more modern, cohesive aesthetic for the Firefox ecosystem. By balancing these design changes with functional updates like hardware AV1 decoding and security patches, Mozilla aims to maintain browser performance while adapting to evolving user interface standards.
