Fake AI trading agent steals crypto wallet passwords
============================================================

Cybercriminals are deploying a sophisticated malware campaign using fake AI trading agents to install the Needle Stealer, which compromises browser-based cryptocurrency wallets and harvests sensitive user passwords.

### Key Points
- HP researchers identified a campaign between April and June 2026 that uses malicious AI trading agent websites to distribute the Needle Stealer malware.
- The malware targets seven popular browser wallet extensions, including MetaMask, Coinbase Wallet, and Phantom, by replacing them with malicious copies to capture passwords.
- Attackers utilize DLL side-loading and process hollowing, leveraging legitimate Microsoft-signed software to bypass Windows SmartScreen security checks.
- Additional campaigns employ "quishing" (QR code phishing) to redirect mobile users to credential-harvesting sites and use steganography to hide loaders within images.
- HP discovered approximately 400 distinct images linked to various credential-stealing campaigns, including those distributing XWorm, PureLogs Stealer, and Formbook.

### Why it Matters
This campaign highlights how attackers are exploiting the growing popularity of AI tools to bypass traditional security defenses and target digital assets. By compromising browser extensions and mobile devices, these threats demonstrate the need for a zero-trust security approach that isolates untrusted downloads and cross-device interactions.
