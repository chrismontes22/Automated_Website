Boris Cherny on Trying to Get Claude Code to Rewrite the Claude App
============================================================

**Claude Code creator Boris Cherny highlights how the new Opus 5 model enables long-running, autonomous AI agents capable of managing complex software development tasks with minimal human intervention.**

### Key Points
- Opus 5 demonstrates significant advancements in long-term task execution, allowing agents to operate for weeks or months without constant manual scaffolding.
- The model shows improved resistance to prompt injection, utilizing mechanistic interpretability to identify and block malicious instructions at the neural level.
- Developers are encouraged to "press delete" on legacy system prompts and rigid code harnesses, as modern models often perform better with fewer manual constraints.
- Claude Code now supports dynamic workflows, enabling the orchestration of thousands of agents to perform complex tasks like full-scale code base migrations.
- Automated maintenance routines, such as dead code removal and abstraction unification, allow AI to manage its own development environment across multiple platforms.

### Why it Matters
The shift toward agentic AI requires developers to move away from rigid, over-specified instructions and adopt an empirical, scientific approach to model interaction. By leveraging "product overhang"—the gap between a model's actual capabilities and current product implementations—founders can build highly autonomous systems that significantly increase engineering productivity.
