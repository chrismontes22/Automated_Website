Your WordPress.com Site is Protected Against the Recent Critical PHP Vulnerabilities
============================================================

The PHP project has released critical security patches for two vulnerabilities that could allow unauthenticated remote code execution, prompting urgent update requirements for self-hosted server administrators worldwide.

### Key Points
- The PHP project issued patches to address two critical vulnerabilities capable of enabling remote code execution.
- Automattic confirmed that all sites hosted on WordPress.com, WordPress VIP, WP Cloud, Pressable, and Tumblr are already protected.
- Administrators managing their own servers must manually update their PHP installations to mitigate these security risks.
- Managed hosting platforms handle infrastructure-level patching, whereas self-hosted users remain responsible for software maintenance and security updates.

### Why it Matters
These vulnerabilities pose a significant threat to the vast portion of the web that relies on PHP, potentially allowing attackers to gain unauthorized control over servers. While managed hosting providers can mitigate these risks automatically, individual site owners must remain vigilant to ensure their infrastructure remains secure against evolving cyber threats.
