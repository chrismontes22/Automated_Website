Apple Fixes Possibly Exploited CoreGraphics Flaw on Older iPhones
============================================================

Apple has released a series of critical software updates across its ecosystem to address a CoreGraphics vulnerability that may have been exploited in targeted attacks against users.

### Key Points
- Apple issued security patches for iOS 26.7.2, iPadOS 26.7.2, iOS 18.7.11, iPadOS 18.7.11, macOS Tahoe 26.7.2, macOS Sequoia 15.8.2, and tvOS 26.6.1.
- The CoreGraphics vulnerability in iOS 18.7.11 allows for arbitrary code execution and affects older devices like the iPhone XS, XR, and seventh-generation iPad.
- Apple confirmed reports that the CoreGraphics flaw was utilized in sophisticated, targeted attacks prior to the release of iOS 27.
- The iOS 26.7.2 and iPadOS 26.7.2 updates include patches for 134 distinct security vulnerabilities.
- The tvOS 26.6.1 update introduces support for the fourth-generation Siri Remote on Apple TV HD and first-generation Apple TV 4K models.

### Why it Matters
These updates are essential for protecting users against active security threats that could allow unauthorized code execution on older hardware. Promptly installing these patches ensures that devices remain secure against known exploits while maintaining compatibility with newer peripheral hardware.
