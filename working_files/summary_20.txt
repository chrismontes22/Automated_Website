AhsayCBS Flaws Exploited to Deploy Web Shells Get New Fixes After Incomplete Patches
============================================================

Ahsay Backup has released critical security hotfixes for its AhsayCBS software to address two vulnerabilities actively exploited by threat actors to deploy web shells and cryptocurrency miners.

### Key Points
- The vulnerabilities, tracked as CVE-2026-105133 and CVE-2026-105134, allow unauthenticated remote code execution when chained together.
- Threat actors have used these flaws to install XMRig cryptocurrency miners and malicious web shells on exposed systems.
- Ahsay released updated hotfixes for versions 10.3.4.45 and 9.15.2.70 after initial patches failed to fully remediate the security risks.
- The U.S. Cybersecurity and Infrastructure Security Agency (CISA) added these flaws to its Known Exploited Vulnerabilities catalog.
- Federal agencies are mandated to apply the necessary patches by the October 17, 2026, deadline.

### Why it Matters
These vulnerabilities pose a significant risk to data integrity and system security for organizations relying on AhsayCBS for backup management. Promptly applying these hotfixes is essential to prevent unauthorized access and the potential deployment of malicious software within corporate networks.
