AWS Client VPN now supports device posture assessment
============================================================

AWS Client VPN now enables device posture assessment, allowing administrators to verify security compliance through integrations with CrowdStrike, Jamf, and JumpCloud before granting network access to resources.

### Key Points
- AWS Client VPN now integrates with CrowdStrike, Jamf, and JumpCloud to evaluate device security signals like encryption status and risk levels.
- Administrators define access requirements using Cedar policies, supported by a new Test Policy tool for validation.
- The system continuously monitors active sessions and automatically disconnects devices that fall out of compliance.
- A monitoring-only mode allows organizations to log evaluation results without enforcing disconnections during the initial rollout.
- The feature is available in all AWS regions at no additional cost and requires AWS VPN Client version 6.2.0 or later.

### Why it Matters
This update strengthens zero-trust security architectures by ensuring that only verified, compliant hardware can access sensitive cloud environments. By automating continuous posture checks, organizations can significantly reduce the risk of compromised devices gaining unauthorized entry to their AWS infrastructure.
