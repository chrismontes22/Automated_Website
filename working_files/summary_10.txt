I turned on system DoH and my browser ignored it completely
============================================================

Windows 11’s built-in DNS over HTTPS (DoH) setting provides encryption for system-level requests, but many applications and web browsers bypass these configurations to manage their own DNS traffic.

### Key Points
- Windows 11 allows users to enable DoH via Network & internet settings by manually configuring DNS servers like Cloudflare’s 1.1.1.1.
- Browsers including Chrome and Edge often ignore system-wide DNS settings, opting to use their own internal secure DNS configurations instead.
- Chromium-based desktop applications, such as Slack, may leak unencrypted DNS queries even when the Windows "fallback to plaintext" feature is disabled.
- Firefox typically defaults to using the Windows system resolver unless a custom DNS provider is manually selected within the browser settings.
- Packet monitoring reveals that some initial DNS lookups occur in plain text before a secure connection is established by individual applications.

### Why it Matters
Relying solely on the Windows 11 DNS privacy toggle provides a false sense of security, as it does not guarantee that all network traffic remains encrypted. Users must verify settings within each individual browser and application to ensure their DNS requests are not leaking or bypassing system-level privacy protections.
