Eight Malicious npm Packages Downloaded 40,767 Times Deliver Overlord RAT and Stealer
============================================================

Cybersecurity researchers from CloudSEK and Checkmarx have identified a malicious npm supply chain campaign dubbed MALFEX that distributes information stealers and remote access trojans to Windows systems.

### Key Points
- The MALFEX campaign has utilized 12 npm packages since August 2023, resulting in over 40,000 total downloads.
- Malicious packages include "function-flag," "function-color," and "cdn-img-fetch," which use postinstall hooks to download and execute hidden payloads.
- The campaign deploys the Overlord RAT, which uses Solana blockchain transactions to retrieve command-and-control server addresses.
- Attackers use the "movinlike" Node.js stealer to harvest sensitive data from Discord, web browsers, Telegram, and cryptocurrency wallets.
- Attribution analysis suggests the threat actor is a Portuguese-speaking individual, likely based in Brazil, operating independently of larger state-sponsored groups.

### Why it Matters
This campaign highlights the ongoing vulnerability of open-source software repositories to supply chain attacks that target developers and end-users alike. Organizations must implement stricter dependency auditing to prevent malicious packages from compromising sensitive credentials and system integrity.
