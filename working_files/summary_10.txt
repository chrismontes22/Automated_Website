Microsoft promises to fix Windows 11 for 8GB PCs, but it put the cart before the horse with low-memory Surfaces
============================================================

Microsoft is actively updating Windows 11 to improve performance on low-memory systems while refining interface elements like context menus to enhance the overall user experience for PC owners.

### Key Points
- Microsoft is optimizing Windows 11 to improve performance on devices equipped with only 8GB of RAM.
- Developers are decluttering the operating system by revamping legacy components and streamlining context menus.
- LG recently removed McAfee advertisements from its PCs after Microsoft intervened regarding software pushed through Windows Update.
- Current market trends show rising RAM costs, making software-level memory optimization essential for budget-conscious consumers.
- Retailers including Amazon and Best Buy are currently offering significant discounts on Surface Pro models featuring 16GB of RAM.

### Why it Matters
These updates address a critical disconnect between Microsoft’s hardware strategy and software readiness, particularly as the company pushes more affordable 8GB RAM devices. Improving memory efficiency ensures that mainstream users receive a reliable experience without needing to invest in expensive high-spec hardware.
