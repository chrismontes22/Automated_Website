DNS has a new encrypted version that isn't DoH or DoT, and almost nobody's adopted it yet
============================================================

DNS over QUIC (DoQ) is an emerging protocol designed to improve internet privacy and connection speeds by streamlining DNS requests through the modern, encrypted QUIC transport layer.

### Key Points
- DoQ eliminates the overhead of HTTP and TCP by running DNS requests directly over the QUIC protocol, which is built on UDP.
- The protocol improves performance by reducing connection handshake times and preventing head-of-line blocking common in older standards.
- Unlike DNS over HTTPS (DoH), which wraps requests in web traffic, DoQ functions as a dedicated, efficient protocol for DNS infrastructure.
- Native support for DoQ is currently absent from major operating systems like Windows, macOS, and mobile platforms.
- Enthusiasts can currently implement DoQ using home DNS server software such as AdGuard Home, Technitium, or dnsproxy.

### Why it Matters
Widespread adoption of DoQ could significantly enhance web security and reduce latency for everyday internet users by modernizing core network communication. Its success depends on major providers like Cloudflare or browser developers integrating the protocol into standard consumer-facing settings.
